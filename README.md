# WDD 430 Portfolio

A personal portfolio site built with Next.js (App Router), TypeScript, and Tailwind CSS for WDD 430: Web Full-Stack Development.

## Tech Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
- Deployed on Vercel

## Features

- Home page displaying a list of projects via reusable components
- About page with a custom skills component
- Reusable, typed Server Components (Header, Footer, ProjectCard, ProjectList, SkillCard)
- Sample API route at `/api/hello`
- Responsive, accessible layout

## Getting Started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
